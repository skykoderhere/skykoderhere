### 🔄 automated upstream sync

The **PawGram** website on this domain (`skye.is-a.dev/PawGram`) automatically tracks upstream updates from [`pawjects/PawGram`](https://github.com/pawjects/PawGram/tree/main/website):

- **Cron Schedule**: `.github/workflows/sync-pawgram.yml` checks for updates every 6 hours and auto-deploys to GitHub Pages.
- **Manual Trigger**: Can be run anytime via **Actions → Sync PawGram Website → Run workflow**.
- **Instant Trigger from PawGram repo**: You can trigger an instant build whenever you push to `PawGram` by adding this step to `PawGram/.github/workflows/notify-portfolio.yml`:

```yaml
# Add in pawjects/PawGram to auto-update skye.is-a.dev/PawGram instantly on push:
name: Notify Portfolio
on:
  push:
    paths:
      - 'website/**'
jobs:
  notify:
    runs-on: ubuntu-latest
    steps:
      - run: |
          curl -X POST https://api.github.com/repos/skykoderhere/skykoderhere/dispatches \
            -H "Accept: application/vnd.github.v3+json" \
            -H "Authorization: token ${{ secrets.PORTFOLIO_SYNC_PAT }}" \
            -d '{"event_type": "pawgram-updated"}'
```
